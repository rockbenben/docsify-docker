# 👋 Welcome to docsify-server / 欢迎使用 docsify-server

This starter page was generated automatically because your `docs` folder had no
`index.html`. Everything here is a normal Markdown file — edit `README.md` to
replace this page, or drop in more `.md` files and link to them.

这个起始页是自动生成的，因为你的 `docs` 目录里没有 `index.html`。这里的一切都是
普通 Markdown —— 编辑 `README.md` 覆盖本页，或放入更多 `.md` 文件并互相链接即可。

## How it works / 工作方式

- The homepage is always `README.md`. / 首页固定是 `README.md`。
- Link to another file with `[Guide](guide.md)` → it opens at `#/guide`. /
  用 `[指南](guide.md)` 链接其他文件 → 访问路径为 `#/guide`。
- Headings (`##`, `###` …) automatically build the table of contents on the right. /
  标题（`##`、`###` …）会自动生成右侧目录。

## Try it / 试一试

1. Create `guide.md` next to this file. / 在同目录新建 `guide.md`。
2. Add a link here: `- [My Guide](guide.md)`. / 在这里加一行链接：`- [我的指南](guide.md)`。
3. Refresh the page. / 刷新页面即可看到。

## Optional files / 可选文件

| File | Purpose / 用途 |
| --- | --- |
| `_sidebar.md` | Custom navigation sidebar / 自定义侧边栏导航 |
| `_navbar.md` | Top navigation bar / 顶部导航栏 |
| `_coverpage.md` | Landing cover page / 封面页 |
| `.nojekyll` | Already included — lets files starting with `_` load / 已自带，允许下划线开头的文件加载 |

> 搜索、目录、图片缩放、字数统计等资产已打包进镜像，本站可完全离线运行。
